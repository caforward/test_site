Корневой и промежуточный сертификаты УЦ Минцифры.

Нужны для обращения к https://securepay.tinkoff.ru - официальному домену
API Т-Банка. Он работает по сертификату Минцифры, которого нет в стандартных
хранилищах Linux, поэтому cURL без этого файла соединение не установит.

Источник: https://www.gosuslugi.ru/crt
  https://gu-st.ru/content/Other/doc/russian_trusted_root_ca.cer
  https://gu-st.ru/content/Other/doc/russian_trusted_sub_ca.cer

Срок действия корневого - до 2032 года. Когда банк или Минцифры обновят
сертификаты, файл нужно будет перевыпустить из тех же источников.
